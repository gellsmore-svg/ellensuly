# Visual experiments

Before locking the grammar, several encodings were tried against the supplier-continuity demo (branching, a shared programme-delay exposure, two capacity-loss exposures of one canonical Risk, a cycle, a low-confidence high-impact node).

## 1. Classic RAG heatmap on every node

Understood in three seconds by risk managers. On a projector it screamed “traffic lights”. It implied a moral ranking of actions that create downstream red nodes. **Rejected** as the default. Kept only as a dedicated heatmap *view*.

## 2. Node size = exposure score

High scores ate the layout. Moderate but central nodes disappeared. **Rejected** as a primary channel. Size is used only as a *slight* scale on the impact lens.

## 3. Continuous rainbow fill

Pretty in demos, unreadable under deuteranopia, no obvious order. **Rejected.** Sequential lightness (cividis-inspired) replaced it.

## 4. Full radar inside every node

The profile is the right idea and the wrong density. At meeting distance it became grey snow. **Rejected** for nodes; **kept** in the drawer.

## 5. Action as a labelled edge, not a node

Collapsed a first-class object back into a verb. Alternative actions could not be compared as landscapes. **Rejected.** Actions are pills.

## 6. Perpetual pulse on imminent risks

Drew the eye and then exhausted it. Conflicts with `prefers-reduced-motion`. **Rejected.** Urgency uses static rings.

## 7. Decision path hides the rest of the graph

Meetings lost the “what are we not choosing?” context. **Revised:** unrelated branches recede; they remain.

## Chosen system

Shape for type. Sequential fill + numerals for exposure. Border weight for impact/connectivity. Rings for urgency. Hatch for uncertainty. Opacity for the decision landscape. Legend of six lines, not a poster.

What survives colour-blindness: shape, kicker text, numbers, hatch, rings, dimming.

What a small legend can explain: the six lenses above.
